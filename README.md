# The 21 Savage Fan Board

A full-stack message board. Post a message, read what others have posted, 
like or dislike messages, and delete messages.

## Live Link

[21 Savage](https://savage-demo-9nml.onrender.com/)

## Features

- Post a message
- Like and dislike messages
- Read messages from other users
- Delete messages

## Built With

- Hosted on Render
- HTML, CSS, JavaScript
- Node.js and Express
- MongoDB

## Installation

1. Clone the repo
2. Run `npm install`

## Usage

1. Run `npm run savage`
2. Go to `localhost:3000`
